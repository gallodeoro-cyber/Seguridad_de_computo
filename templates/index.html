¿Qué medidas de seguridad demuestra esta app?

Validación y normalización. El servidor comprueba los campos y aplica reglas consistentes antes de guardar los datos.

Consultas parametrizadas. SQLite recibe los valores como datos separados de las instrucciones SQL.

Salida escapada. Las plantillas muestran el texto de los usuarios sin interpretarlo como HTML.

Errores seguros y código reutilizable. Los mensajes públicos evitan detalles internos. El README explica las funciones compartidas y las pruebas de seguridad.
